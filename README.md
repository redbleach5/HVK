# Тихая редакция

Тихая подруга для автора блога **«Красивое в обычном 🤍»**.

Она не пишет посты за тебя. Она смотрит на твои фото, бережно правит черновики, помнит, что тебе откликается, и объясняет каждое предложение — почему именно сейчас.

## Что умеет

- **Чат** — основной интерфейс: сводка, идеи, фото, редактура, ЛС, план, аналитика и публикация с подтверждением
- **Telegram** — то же в кармане: фото, текст, `/today`, `/ideas`, `/stats`

С каждым «учту» или «не соглашусь» она чуть лучше понимает твой вкус.

## Как открыть

Всё живёт на одном Windows-компьютере с видеокартами — там и модели, и сама редакция.

Запуск: `scripts\start.bat`.  
Остановка: `scripts\stop.bat`.

- **На этом же компьютере** открой в браузере http://127.0.0.1:8501
- **С Mac или телефона в той же Wi‑Fi сети** — http://IP-этого-компьютера:8501  
  (IP можно посмотреть в настройках Windows: «Параметры → Сеть». В брандмауэре разреши порт 8501.)

Работать с Mac удобно: интерфейс открыт у тебя под рукой, а «тяжёлая» работа остаётся на Windows. Модели и API снаружи сети не торчат — наружу выходит только тёплый экран редакции.

Всё личное (токены, пути к моделям) живёт в `.env` под капотом — в интерфейсе этого нет.
