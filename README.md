# Тихая редакция

Локальная LLM-система для автора личного лайфстайл-блога ВКонтакте.

## Описание

Система — ассистент, не автор. Она анализирует фото, редактирует черновики, понимает аудиторию и предлагает идеи. Каждое решение остаётся за автором.

Тихая подруга для автора блога **«Красивое в обычном 🤍»**.

Она не пишет посты за тебя. Она смотрит на твои фото, бережно правит черновики, помнит, что тебе откликается, и объясняет каждое предложение — почему именно сейчас.

## Особенности

- **Память**: система помнит автора и её блог между сессиями
  - Предпочтения: любимые темы, цвета, форматы, ритуалы автора
  - Уроки: что заходило аудитории, что провалилось, и почему
  - Антипатии: что автор отвергла или уже делала недавно
  - Ритм автора: когда она обычно постит, какие дни активнее

- **Обратная связь**: система запоминает выбор автора и корректирует будущие предложения
- **Контекстный движок**: система собирает контекст перед каждым предложением
- **Объяснимость**: каждое предложение сопровождается объяснением
- **Живой профиль голоса**: профиль строится из постов автора и обновляется после каждой публикации

## Агенты

- **Фото-аналитик**: оценивает фото как арт-директор lifestyle-журнала
  - Атмосфера, композиция, свет, палитра, сторителлинг
  - Сравнение с прошлыми фото автора

- **Редактор текста**: редактирует черновик сохраняя голос автора
  - Не меняет смысл, не добавляет фактов
  - Возвращает результат с объяснением каждой правки

- **Аналитик аудитории**: статистика постов VK + комментарии
  - Портрет аудитории, что работает и почему
  - Частые вопросы, неудовлетворённые запросы

- **Генератор идей**: идеи контента с учётом сезона, памяти и контекста
  - Тема, формат, личный угол автора, визуальное направление
  - Обоснование "почему именно сейчас"

- **Консьерж ЛС**: классифицирует входящие сообщения и готовит черновики ответов
  - Не отправляет ничего автоматически

- **Архив**: векторный поиск по постам автора (ChromaDB)
  - Поиск похожего, предложение переиспользовать старый контент

## Интерфейс

Система предоставляет два интерфейса:

1. **Веб-интерфейс** (Streamlit) — главный дашборд с пятью вкладками:
   - **Сегодня** — утреннее резюме
   - **Фото** — разбор кадра и направление для подписи
   - **Текст** — редактура в твоём голосе
   - **Идеи и план** — генерация идей с перетаскиванием в план
   - **Аналитика** — графики вовлечённости и инсайты

2. **Telegram-бот** — мобильное продолжение дашборда:
   - Пришли фото — разберу
   - Текст от 50 символов — мягко отредактирую
   - /today — утреннее резюме
   - /ideas — три идеи
   - /stats — мини-отчёт недели

## Требования

- Python 3.11+
- Windows
- LLM-модели (llama.cpp)
- Две модели: Qwen 3.8 27B для текстов и Gemma 4 12B для фото

## Установка и запуск

1. Склонируйте репозиторий
2. Запустите `scripts\start.bat` (создаст виртуальное окружение и установит зависимости)
3. Откройте интерфейс по адресу http://127.0.0.1:8501

## Структура проекта

- `app/` — backend FastAPI
- `bot/` — Telegram-бот
- `ui/` — Streamlit-интерфейс
- `data/` — данные приложения
- `scripts/` — скрипты запуска и остановки

## Как открыть

На компьютере, где живёт редакция: `scripts\start.bat`, затем http://127.0.0.1:8501  
Остановка: `scripts\stop.bat`.

С телефона в той же Wi‑Fi: http://IP-этого-компьютера:8501
